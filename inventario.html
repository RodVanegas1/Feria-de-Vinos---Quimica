Sí, se puede por GitHub y es mejor que OneDrive: todos abren la misma URL y los cambios se suben al repo solos, sin reemplazar archivos a mano. Necesitas 1 repo + 1 token (solo lo crea 1 persona, luego comparte la config).

  1. En GitHub crea un repo público (ej: inventario-mosto) y sube inventario.html + datos.js. Activa Settings → Pages → Deploy from branch → main /(root). Te dará una URL tipo https://TU-USUARIO.github.io/inventario-mosto/inventario.html. Esa URL la abren los 5.
  2. Crea un token: GitHub → foto perfil → Settings → Developer settings → Personal access tokens → Fine-grained → Generate → solo ese repo → permiso Contents: Read and write → copiar el github_pat_….
  3. Llena esto (una vez) y pulsa Conectar. Luego comparte con el equipo el mismo owner/repo/path (el token puedes ponerlo tú en cada PC o usar 1 token compartido solo para este repo).
